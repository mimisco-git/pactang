# PactaNG

Post-award procurement control for Nigerian public contracts.

## Stack

Next.js 15, TypeScript, Tailwind CSS 4, Framer Motion, Lucide, React Three Fiber, Lenis.

## Run

```bash
npm install --legacy-peer-deps
npm run dev
```

Open http://localhost:3000 then Launch demo project.

## Deploy on Vercel

1. Import https://github.com/mimisco-git/pactang
2. Framework: Next.js
3. Install command: `npm install --legacy-peer-deps`
4. Build command: `next build`
5. Deploy
